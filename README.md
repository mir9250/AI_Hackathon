# true — 내 피부를 위한 스킨케어

실행: `python3 실험용.py` → http://localhost:8000

브랜드 색상 `#88B9FF`를 사용하는 반응형 HTML/CSS/JavaScript 화면 프로토타입입니다.

- 최초 진입: 로그인 화면. 로그인 없이 둘러보기 가능
- `#home`: 화장품 검색 및 추천 상품
- `#login`: 이메일·비밀번호 입력을 통한 데모 로그인
- `#profile`: 닉네임, 피부 타입, 피부 고민 입력
- `#categories`: 카테고리 → 스킨케어
- `#products`: 기초화장품 6종 목록, 카테고리 필터 및 검색
- `#compare`: 서로 다른 두 제품의 별점, 피부 타입, 장단점 비교
- 검색 결과의 상품 선택 시 별점 분석 화면 표시. 직접 진입 시 검색 화면으로 안내
- 비로그인 상태에서는 피부 맞춤 별점을 모자이크로 가리고 로그인 링크 표시
- 로고 옆 메뉴 버튼으로 전체 메뉴 열기. Escape 또는 바깥 클릭으로 닫기

모든 상품, 리뷰, 별점은 가상 데이터입니다. 맞춤 별점은 화면 체험용 예시 수치이며 실제 분석 결과가 아닙니다. 실제 인증, 서버 저장, 리뷰 수집 및 AI 분석은 구현하지 않았습니다. 이메일과 비밀번호는 저장하거나 전송하지 않으며, 피부 프로필은 현재 페이지 메모리에서만 사용됩니다. 새로고침하면 초기화됩니다.

외부 패키지 없이 실행됩니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.
