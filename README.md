# true — 나를 위한 진짜 별점

실행: `python3 실험용.py` → http://localhost:8000

외부 패키지 없이 실행하는 반응형 MVP입니다. 가상 제품의 샘플 리뷰 12개로 동작합니다.

- 광고/협찬, 과장 표현, 장기 사용, 실사용, 구체성에 따른 가중 평균
- 건성/지성/복합성/민감성 선택 시 해당 리뷰에 1.8배 가중치 적용
- 피부 타입별 장단점 키워드 빈도, 리뷰 필터, 직접 리뷰 입력 및 즉시 재계산
- 분석 기준 설명 모달

현재 분석은 JavaScript 키워드 규칙이며 실제 AI 모델이 아닙니다. 피부 타입은 샘플의 자기 기재 정보이며, 직접 입력 시 본문의 키워드로 추정합니다. 입력 리뷰는 메모리에만 저장됩니다. 협찬 감점 등 수치는 검증 전 가설입니다. 장단점 요약은 부정 문맥을 이해하지 않는 단순 표현 집계입니다.

다음 단계: 리뷰 수집/입력 API → AI 구조화 분석(피부 타입, 협찬 근거, 사용 기간, 장단점, 확신도) → 검증 데이터로 가중치 보정 → DB 저장. AI 호출은 API 키를 노출하지 않는 서버에서 수행해야 합니다.
