# 돌려받집

**입주부터 퇴실까지, 우리 집의 변화를 기록하고 보증금 정산을 준비하는 웹 서비스입니다.**

월세 거주자가 입주·퇴실 사진과 메모를 보관하고, 거주 중 수리·누수·임대인 협의 내용을 일지로 남길 수 있습니다. 사진·특약·전후 비교를 살펴보는 AI 분석 연동 코드도 포함합니다.

**[공개 데모 열기](https://dollyeobatjip-demo.newflask.chatgpt.site)** · [저장된 기록](https://dollyeobatjip-demo.newflask.chatgpt.site/#archive) · [생활 일지](https://dollyeobatjip-demo.newflask.chatgpt.site/#journal)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 입주·퇴실 기록 | 현관·바닥, 욕실·실리콘, 창틀·창문, 벽지·모서리의 사진·상태·메모 저장 |
| 저장된 기록 모아보기 | 공간 기록, 생활 일지, AI 결과를 유형별로 분류하고 검색 |
| 생활 일지 | 수리·누수·하자 발견·임대인 협의·비용 정산을 날짜별로 작성·수정하고 진행 상태 표시 |
| 계정 저장·복원 | 배포 사이트에서 로그인 후 사진·메모·일지를 계정에 저장하고 다른 브라우저에서 불러오기 |
| 계약서 체크 | 입력한 특약의 키워드 확인 및 동의 후 AI 분석 |
| 퇴실 전후 비교 | 입주·퇴실 사진을 슬라이더로 비교하고 AI 변화 관찰 요청 |
| 보증금 대응 | 공제 내역과 근거를 확인하는 요청 문장 작성·복사 |
| 리포트 내보내기 | 저장한 사진·메모·일지·AI 참고 결과를 HTML 파일로 다운로드 |

화면은 노란색 `#FFD966`을 중심으로 구성했습니다. 공간별·입주/퇴실별 사진은 각각 최신 1장을 보관하며, 전체 사진 버전 이력을 제공하지는 않습니다. 생활 일지는 최대 100개, 제목 80자, 내용 2,000자입니다.

## 배포 사이트와 로컬 실행의 차이

| 항목 | 공개 데모 | 로컬 Python 서버 |
| --- | --- | --- |
| 화면·기록·일지·리포트 | 사용 가능 | 사용 가능 |
| 로그인 | ChatGPT 로그인 후 닉네임·저장 동의로 프로필 등록 | 플랫폼 로그인 미제공 |
| 데이터 저장 | 계정별 D1 메타데이터·비공개 R2 사진, IndexedDB 기기 캐시 | IndexedDB 기기 저장 |
| 다른 브라우저에서 복원 | 같은 계정으로 로그인하고 서버에 저장된 기록 복원 | 계정 동기화 미제공 |
| 사진 크기 제한 | 사진당 4MB, 계정 사진 합계 128MB | 사진당 8MB |
| AI 분석 | 배포 서버의 API 키 설정 필요 | 로컬 서버의 API 키 설정 필요 |

배포 사이트의 AI 키는 마지막 확인 시 미설정 상태입니다. 분석 코드는 구현되어 있으나 실제 AI 결과는 서버 설정 후 생성됩니다. 현재 상태는 화면 상단의 AI 상태와 `/api/health`에서 확인할 수 있습니다.

PWA 설치용 manifest와 service worker는 아직 추가하지 않았습니다. 현재는 웹사이트로 사용합니다.

## 로컬에서 실행하기

Python 3.9 이상이 필요하며, 기본 실행에 외부 패키지 설치는 필요하지 않습니다. 저장소 루트에서 실행하세요.

```bash
python3 rental-demo/server.py
```

브라우저에서 **http://localhost:8001/** 에 접속합니다. `python3 실험용.py`로도 같은 서버를 실행할 수 있습니다. API 키 없이 사진·메모·일지 저장, 수동 비교, 특약 키워드 확인, 리포트를 체험할 수 있습니다.

AI 분석을 사용하려면 `.env` 파일이 없는 경우 예제 파일을 복사합니다.

```bash
cp rental-demo/.env.example rental-demo/.env
```

`rental-demo/.env`의 `OPENAI_API_KEY`를 설정한 뒤 서버를 재실행합니다. 기본 모델은 `gpt-4.1-mini`, 기본 포트는 `8001`이며 `OPENAI_MODEL`, `PORT`로 변경합니다. 키는 서버에서만 읽으며 GitHub·채팅·클라이언트 JavaScript에 넣지 않습니다.

## 계정과 기록 저장

1. 배포 사이트의 **내 계정 · 동기화**에서 ChatGPT로 로그인합니다.
2. 처음 방문하면 닉네임과 서버 저장 동의로 프로필을 등록합니다. 비밀번호는 플랫폼 인증에서 관리합니다.
3. 사진·메모·일지를 저장하고 상단의 **계정에 저장됨** 상태를 확인합니다.
4. 다른 브라우저에서도 동일한 ChatGPT 계정으로 로그인해 기록을 불러옵니다. 브라우저마다 첫 로그인은 필요합니다.

비회원 기록은 해당 브라우저에 저장합니다. 로그인 후에는 명시적인 가져오기 절차로 계정에 옮기며, 서버에 기존 기록이 있으면 덮어쓰기를 차단합니다. 다른 기기의 변경과 충돌한 경우에도 자동으로 덮어쓰지 않습니다.

생활 일지의 임시 작성 내용도 저장하지만, 목록·리포트에는 **일지 저장**을 완료한 항목만 포함합니다. 비회원 기록과 미동기화 자료는 브라우저 데이터 삭제 시 잃을 수 있으므로 중요한 사진 원본과 리포트는 별도 보관하세요.

## 검증

저장소 루트에서 실행합니다. JavaScript 테스트에는 Node.js가 필요합니다.

```bash
python3 -m unittest discover -s rental-demo -p 'test_*.py' -v
node rental-demo/smoke-test.cjs
node rental-demo/records-test.cjs
node rental-demo/storage-smoke-test.cjs
node rental-demo/photo-flow-test.cjs
node rental-demo/ai-smoke-test.cjs
node rental-demo/ai-unconfigured-test.cjs
```

위 테스트는 기록·일지 흐름, 저장, 입력 검증, AI 요청·응답 처리를 확인합니다. AI 테스트는 모의 응답을 사용합니다. 계정 DB 왕복·기기간 복원·계정 분리 테스트는 별도 배포 소스에서 수행했습니다. 실제 사용자 로그인, 카메라, 화면 배치와 유료 모델 호출은 별도 검수가 필요합니다.

## 현재 범위와 팀 작업

AI 분석은 사용자가 전송 범위를 확인하고 동의한 뒤 요청할 때 실행됩니다. 하자 원인·발생 시점·통상 마모·배상 책임·수리비·보증금 반환 여부를 확정하는 기능은 아닙니다. 법령 검색/RAG는 미연결이며, 입력한 발생일과 기기 기록 시각은 공인 시점 인증이 아닙니다.

새 작업은 작업별 브랜치에서 진행합니다. 변경 사항 검증 후 커밋·푸시하며, `main` 반영은 [팀 공통 규칙](AGENTS.md)을 따릅니다.
