# 돌려받집 임대차 법률 선별 데이터셋 v0.1

조회일: 2026-11-15. 대한민국 임대차의 입주·생활·퇴실 기록과 보증금 정산 준비에 초점을 맞춘 **수작업 선별 초기 자료 15건**이다. 정부가 배포한 완성 데이터셋이나 법률 전문가 검토가 완료된 자료가 아니다. 기존 앱에는 아직 연결하지 않았다.

## 구성

- 조문 10건: 민법 제536·615·623·626·627·634·654조, 주택임대차보호법 제4조·제6조의2·제3조의3 중 제1·5·8항.
- 판례 5건: 대법원 94다34692·94다34708(병합 사건 1건), 2023다249661, 87다카1315, 77다1241, 서울지방법원 98가합44951.
- 조문 10건과 판례 4건은 국가법령정보센터가 제공하는 원문을 직접 확인했다. 판례는 판결요지 선별 발췌이며 전문 전체는 수록하지 않았다.
- 98가합44951은 법제처 해설의 인용만 확인했다. 정식 사건명·전체 사실관계·확정 여부·후속 판례는 미확인이다. `official_secondary_only`이며 자동 답변 근거에서 제외해야 한다.
- 민법의 법령 버전 표시는 시행 2026-03-17, 법률 제21454호다. 주택임대차보호법은 시행 2026-01-02, 법률 제21065호다. 이는 **사이트에 표시된 법령 전체 버전의 시행일**이지 각 조문이 그날 개정됐다는 의미가 아니다.

## 파일과 필드

- `rental-law.json`: 설명·제한과 records 배열을 담은 구조.
- `rental-law.jsonl`: 한 줄당 한 레코드. 각 줄에 검토 상태와 공통 주의사항도 포함한다.
- `rental-law.csv`: 엑셀 호환 UTF-8 BOM. 배열은 JSON 문자열이고 날짜는 YYYY-MM-DD다. 빈 날짜는 해당 없음이다.
- `manifest.json`: 파일별 SHA-256과 건수. 출처의 공인 인증이나 법적 정확성 인증이 아니라 파일 변경 확인용이다.

`id`는 내부 연결용 식별자, `citation`은 인용 표기, `type`은 statute 또는 case, `topics`는 편집자가 붙인 검색 주제다.

`source_url`·`source_publisher`는 확인한 출처다. `source_quote`는 공백 정규화한 원문 발췌이고, 발췌 범위·생략 여부는 `source_scope`에 명시했다. `summary`·`cautions`·`evidence_to_prepare`는 **편집 요약과 제안**이며 법원이나 법제처가 작성한 문장으로 제시하면 안 된다. 준비자료를 모았다고 증명력이 보장되지는 않는다.

`verification_level=primary_text_checked`는 해당 출처의 텍스트를 확인했다는 뜻일 뿐 최신 법리 확인이나 전문가 검토 완료 표시가 아니다. `official_secondary_only`는 공식 기관의 2차 해설만 확인한 경우다.

`law_version_effective_on`은 법령 버전 시행일, `decision_on`은 선고일, `retrieved_on`은 실제 조회일이다. 다시 조회하지 않고 조회일을 갱신해서는 안 된다. `related_ids`는 편집자가 연결한 항목이지 판결의 모든 참조조문 목록은 아니다.

`reference_eligible_after_legal_review=true`는 **별도 법률 검토 후 참고 후보**라는 의미다. 현재 `legal_professional_reviewed=false`, `production_ready=false`이므로 서비스 사용 승인으로 해석하면 안 된다. false 항목은 원문 추가 확인도 필요하다. `court`·`case_numbers`·`original_context`는 판례에만 있다.

## 사용 제한과 검토 절차

1. 검색·화면 시제품과 검토용 초기 자료이며 법률 자문·자동 책임 판정·승소 예측용이 아니다.
2. 사진의 변화가 보인다는 사실과 원인·과실·비용 부담은 다르다. 손상 분류, 수리비, 공제 비율, 자재 내용연수의 정답 데이터는 포함하지 않는다.
3. 여관·토지·다방 사건을 주택의 동일 사안으로 설명하면 안 된다. `original_context`와 `cautions`를 함께 읽어야 한다.
4. 사건·계약·종료 시점의 법령, 부칙·경과규정, 후속 판례와 특약의 효력을 전문가가 재검토해야 한다. 최신 유효성과 상·하급심 이력 전수 조사는 하지 않았다.
5. 인용되는 다른 조문을 모두 수록하지 않았다. 대항력·우선변제·갱신요구권·상가임대차·세금·경매의 포괄 데이터셋이 아니다.
6. 원문·편집 요약을 구분하고 출처·조회일·주의사항을 결과에 유지해야 한다. 법제처 생활법령 해설은 법적 효력을 갖는 유권해석이 아니다.
7. 웹페이지 전체, 해설·편집물·첨부물의 이용허락을 포괄적으로 주장하지 않는다. 공개 서비스·상용 재배포 전 제공처 약관과 이용조건을 확인해야 한다.
8. 자동 갱신 기능은 없다. 개정이나 신규 판례가 확인되면 자료를 다시 읽고 변경 이력을 남긴 뒤 내보내야 한다.

## 확인 출처

- 국가법령정보센터 조문정보 및 공개 판결: 각 레코드의 `source_url`. 일반 법령 화면은 본문이 비어 반환되는 경우가 있어 실제 조문을 제공한 조문정보 화면으로 확인했다.
- 법제처 찾기쉬운 생활법령정보 「임차기간 만료 후, 도배 및 청소비용을 물어줘야 하나요?」, 평결일 2012-04-23: https://www.easylaw.go.kr/CSP/SolomonRetrieve.laf?sortType=REGDT&topMenu=serviceUl6&trialNo=1004
- 보조 확인: 법제처 「임대인의 권리·의무」(페이지 기준일 2026-10-15), https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=4&cciNo=2&cnpClsNo=2&csmSeq=629&menuType=cnpcls&popMenu=ov
- 보조 확인: 법제처 「종전 임차인이 설치한 가건물도 임차인의 원상회복 의무에 따라 철거해야 하나요?」(평결일 2024-07-16), https://www.easylaw.go.kr/CSP/SolomonRetrieve.laf?sortType=REGDT&topMenu=serviceUl6&trialNo=2288

## 프로젝트에서 다시 내보내기

원본은 `data/rental-law/records.json`이다. `python3 scripts/export-rental-law.py`는 외부 조회 없이 구조·날짜·중복·참조 연결을 검사하고 `.baze-files/outputs/` 아래 JSON·JSONL·CSV·설명서와 ZIP을 만든다. 내용의 법적 정확성을 자동 검증하는 기능은 아니다.

## 이번 작성 시 확인 결과

2026-11-15에 15건 모두 출처 페이지를 다시 조회해 저장한 발췌 문구가 일치함을 확인했다. 비교 시 공백과 개정 주석은 제외했다. 98가합44951의 일치는 판결 원문이 아니라 법제처 해설과의 일치다. 중복 식별자·연결 대상·날짜 형식·출력 15행·CSV 발췌 보존 검사와 변경 파일 공백 검사를 통과했다. 이 검사는 후속 판례에 의한 변경이나 법률적 해석을 검증하지 않는다. 앱 화면과 기능은 변경하지 않아 화면 검사는 이번 자료 검증에 포함하지 않았다.
