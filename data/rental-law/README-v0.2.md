# 돌려받집 임대차 판례 자료 v0.2

## 내용과 선별 방식

기존 조문 10건을 유지하고, **판례를 기존 5건 포함 총 120건**으로 확장했다. 동일 사건번호를 포함하는 병합 사건은 하나로 세고 중복 사건번호를 제거했다.

기존 5건은 수작업 선별 자료다. 추가 115건은 국가법령정보센터 공개 검색을 보증금 반환·원상회복·수선 의무·계약 종료·보증금 보호·계약 갱신·정산·임차권등기 주제로 조회한 뒤, 실제 공개 판결요지와 메타데이터가 있고 임대차 관련 용어가 포함된 사건을 수집했다. 주제 순환으로 수집하지만 건수별 균등 할당이나 법리의 대표성·완전성을 보장하지 않는다. **120건 전부를 법률 전문가가 수작업 선별·검토한 자료가 아니다.**

검색 당시 공식 출처에서 확인한 실제 인용 문구만 저장한다. 판결 전문의 당사자 정보는 저장하지 않는다. 추가 자료의 `source_quote`는 공개 판결요지 전체, `source_issues`는 판시사항이다. 추가 자료의 `summary=null`은 편집 요약이 없다는 뜻이다. 화면의 목록 미리보기는 원문 앞부분을 잘라 보여주며 AI 요약이 아니다.

원문을 확인한 자료와 법제처 해설에서만 확인한 하급심 1건(98가합44951)을 `verification_level`로 구분한다. 후자는 원문 확인·자동 답변 근거로 취급하지 않는다. 일반 판례 검색에서는 경고와 함께 볼 수 있다. `primary_text_checked`도 법리의 현행 유효성·전문가 검토 완료를 의미하지 않는다.

## 파일

- `rental-law.json`: 조문 10건 + 판례 120건, 메타데이터·제한·수집 결과 포함.
- `rental-cases.jsonl`: 판례만 한 줄에 한 건, 주의사항 포함.
- `rental-cases.csv`: 판례 120건, 엑셀 호환 UTF-8 BOM. 배열은 JSON 문자열이다.
- `collection-report.json`: 목표·실제 건수, 확인 후보 수, 제외된 후보와 이유, 검색 주제. 중복 판례는 본 자료에 재수록하지 않는다.
- `manifest.json`: 파일 해시와 건수. 법적 정확성 인증이 아닌 파일 변경 확인용이다.

## 주요 필드

`citation`·`court`·`case_numbers`·`decision_on`은 인용·법원·사건번호·선고일이다. `source_url`·`source_publisher`는 확인 출처, `source_scope`는 발췌 범위, `retrieved_on`은 조회일이다. 추가 자료의 `source_quote_sha256`은 원문 발췌의 해시다. `discovered_from`은 발견한 공식 검색 페이지다. `topics`는 검색 주제 분류이지 판결의 법률적 결론 라벨이 아니다.

`original_context`는 기존 5건에서는 편집한 배경, 추가 115건에서는 공식 판시사항이다. `curation_method`로 구분한다. `summary`·`cautions`·`evidence_to_prepare` 중 값이 있는 편집 내용은 법원 문구와 구별해야 한다. 준비자료를 모았다고 증명력이 보장되지는 않는다.

`reference_eligible_after_legal_review=true`는 별도 전문가 검토 후 참고 후보라는 의미일 뿐 사용 승인 표시가 아니다. `legal_professional_reviewed=false`, `production_ready=false`를 유지했다. false인 자료는 추가 원문 확인도 필요하다. 법령 시행일은 법령 전체 버전 기준이며 개별 조문 개정일과 다를 수 있다.

## 적용 제한

법률 자문·자동 책임 판정·공제액 산정·승소 예측용 정답 데이터가 아니다. 주택 외 상가·토지 등도 포함되어 있으므로 실제 임대 대상, 계약·특약, 시점별 법령과 부칙, 후속 판결을 확인해야 한다. 후속 변경·폐기와 상하급심 이력을 전수 조사하지 않았다. 검색어 일치나 사진만으로 동일한 결론을 제시하면 안 된다. 공식 해설은 법적 효력을 갖는 유권해석이 아니다.

원문 발췌·편집 설명·출처·조회일·주의사항을 구분하고 유지해야 한다. 공개 서비스·상용 재배포 전 제공처 이용조건과 전문가 검토가 필요하다. 웹사이트 전체·제3자 해설·편집물의 이용허락을 포괄적으로 주장하지 않는다. 자동 갱신 기능은 없다.

## 서버 연결

기존 앱에 읽기 전용 판례 검색과 상세 조회를 추가했다. 로그인이나 개인 기록 없이도 공개 판례를 조회할 수 있고, 검색어는 별도로 저장하거나 AI로 전송하지 않는다. 검색 인프라의 기본 접속 로그에 요청 경로가 남을 수 있으므로 개인정보를 검색어에 넣지 않아야 한다.

서버는 패키지에 포함된 고정 자료를 읽는다. 이용할 때마다 외부 사이트를 수집하지 않는다. 보증금·책임 판정 및 기존 사진·계약서 AI 프롬프트에는 자동 삽입하지 않았다. 판례 검색 연결과 AI 법률 판단 연결은 구별한다.

개발자용: `GET /api/legal/cases`는 q(최대 100자), topic, source(all/primary), limit(1~30), offset으로 검색한다. `GET /api/legal/cases/{id}`는 원문 발췌·주의사항을 반환한다. 없으면 404, 자료 누락·손상이면 503이다. Render의 backend 기준 경로에서도 자료가 포함되도록 `backend/app/data/rental-law-v0.2.json`을 배포물에 둔다.

원본은 `data/rental-law/records-v0.2.json`, 내보내기는 `python3 scripts/export-rental-cases.py`, 동기화 검사는 `python3 scripts/export-rental-cases.py --check`다. 재수집은 `python3 scripts/collect-rental-cases.py`를 명시적으로 실행할 때만 하며 외부 요청이 발생한다. 기존 v0.1 자료·설명서는 보존했다.
