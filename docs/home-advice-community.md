# 집 관리 질문·커뮤니티·사진 위치 확인

작업 브랜치: `feat/home-advice-community`. 기존 운영 배포와 main에는 아직 반영하지 않았다.

## 변경

- 메인 검색을 메뉴 필터에서 집 관리 질문으로 변경했다. 기록 메뉴는 질문과 무관하게 유지한다.
- 서비스명·로고 클릭 시 하위 화면 요청을 정리하고 계정 정보를 다시 조회해 메인 화면으로 복귀한다.
- 공식 자료를 요약한 18개 집 관리·임대차 주제를 제공한다. 출처와 확인 날짜, 책임 판단 조건, 추가 확인 질문을 표시한다. 실시간 웹 검색이나 생성형 법률 상담은 아니다. 사실관계 없는 책임 비율은 만들지 않는다.
- 커뮤니티는 로그인한 회원 간 글·댓글을 공유하며 본인 작성물 삭제를 지원한다. 개인 주택·사진·계약서 자료는 공유하지 않는다. 별도의 SQL 적용이 필요하며, 적용 전에는 저장소 준비 안내가 표시된다.
- 입실/퇴실 AI가 위치 불일치 또는 식별 불가를 반환하면 위치 확인 불가 표시와 재촬영 안내를 제공한다. 기존 분석 스키마를 유지한다. 이미 완료된 기존 분석은 자동 재분석하지 않는다.

## 검증 및 적용

백엔드 pytest 전체 통과, 프론트 Node 테스트와 Vite 빌드 통과. 커뮤니티 권한은 PGlite에서 타인 글/댓글 삭제 거절, 작성자 위조 거절, 공개 읽기 범위, 글 삭제 시 댓글 정리를 검증한다.

실제 AI 사진 호출, 운영 로그인/커뮤니티 등록, 모바일 브라우저 시각 검증은 실행하지 않았다. 운영 적용에는 커뮤니티 SQL 적용, FastAPI 업데이트, 프론트 빌드·배포가 모두 필요하다. 원격 main 병합·푸시는 사용자 요청 시 저장소 AGENTS.md 절차에 따라 진행한다.
