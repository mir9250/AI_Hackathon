# 임대차 판례 120건 연결

## 범위

v0.1의 조문 10건과 판례 5건은 보존했다. v0.2는 판례를 총 120건으로 늘리고 읽기 전용 검색·조회만 추가한다. 사진·계약서 AI 프롬프트, 사용자 기록, 권한, 기존 저장 표는 변경하지 않는다. 전문가 검토 전 참고자료라는 한계를 유지한다.

기존 5건 이외 자료는 공식 검색 주제와 임대차 용어 필터로 수집한 판결요지다. 전문가 수작업 선별 자료로 설명하면 안 된다. 주택 외 임대차 사건도 포함한다. 사건번호별 중복을 제거하며 병합 번호의 축약도 풀어 보존한다. 98가합44951은 공식 해설에서만 확인한 항목으로 구분하고 자동 답변 근거에서 제외한다.

## 운영 경로

- `backend/app/legal.py`의 공개 읽기 전용 경로를 기존 FastAPI 앱에 등록한다.
- 목록: `/api/legal/cases?q=보증금&source=primary&limit=10&offset=0`
- 상세: `/api/legal/cases/{id}`
- 검색어 100자, 주제 30자, 페이지 1~30건, offset 0~1000 제한. 미등록 id는 404, 자료 손상·누락은 503.
- 응답에 원문/공식 해설 확인 구분, 전문가 미검토, 출처·선고일·조회일·주의사항을 제공한다.
- 공개 자료만 조회하므로 로그인은 필요 없다. 검색 시 외부 법률 사이트·AI·사용자 저장소를 호출하지 않는다. 검색어를 별도 저장하지 않지만 기본 접속 로그의 요청 경로에는 남을 수 있다.
- 기존 웹 중계의 `/api/*` 전달 구조를 사용하므로 개인 토큰 전달이나 권한 검사를 변경하지 않는다.
- 집 관리 도움말 안의 ‘임대차 판례 찾아보기’는 펼칠 때만 조회한다. 쟁점·사건번호·주제·출처 확인 범위로 검색하고 상세·공식 출처를 볼 수 있다. 사용자·원문 텍스트는 HTML이 아니라 textContent로 표시한다. 화면이 사라질 때 진행 중 조회도 취소한다.

## 배포 자료와 실행

원본은 `data/rental-law/records-v0.2.json`, 실행 시 자료는 `backend/app/data/rental-law-v0.2.json`이다. Render의 rootDir=backend 범위 안에 자료가 존재한다. JSON/JSONL/CSV/설명서/수집 보고서/해시 목록을 `.baze-files/outputs/rental-law-v0.2.zip`으로 생성한다.
별도로 `.baze-files/outputs/rental-cases-120.csv`를 제공하며 압축 파일의 CSV와 같은 내용인지 검사한다.

`python3 scripts/export-rental-cases.py`로 자료를 검증하고 패키징한다. `--check`는 서버 자료·원본·다운로드의 일치를 확인한다. 수집기는 `scripts/collect-rental-cases.py`이며 실행할 때만 공식 사이트를 직렬 조회한다. 차단·호출 제한 응답은 우회하지 않고 중단한다. 자동 수집이나 예약 실행은 없다.

프로젝트 루트의 `npm run dev`는 기존 읽기 전용 화면 미리보기와 실제 공개 판례 조회만 실행한다. 실제 로그인·저장·AI를 성공한 것처럼 흉내내지 않는다. 기존 운영 Render 시작 방법은 그대로 유지한다.

## 검증

추가 검사는 판례 건수·사건번호 중복·인용 해시·서버 자료 일치·다운로드 무결성, 공개 조회·페이지·검색·출처 필터·없는 id·입력 제한·자료 누락 오류, 화면의 안전한 텍스트 표시·상세 조회·재검색이다. 변경된 화면은 데스크톱·모바일에서 실제 공개 판례 조회로 확인한다. 기존 기능 회귀 검사도 실행한다.

이 문서는 코드 연결 범위를 설명한다. main 반영과 운영 반영은 별개이며 운영 반영 여부는 실제 주소의 새 경로 응답과 배포된 커밋을 확인한 뒤 보고한다. 운영 관리 권한이 없으면 재배포 완료라고 주장하지 않는다.

### 중간 검증 기록

화면 검사 85건, 기존 기능 검사 287건(신규 자료 의존 검사 제외), 중계 검사 4건과 병합 사건번호 검사 1건이 통과했다. 운영용 화면 빌드도 통과했다. 전체 자료 수집·내보내기 완료 후 새 판례 검사 및 실제 데스크톱·모바일 검색 흐름을 확인해야 한다. 아직 커밋·main 반영·운영 반영 완료를 뜻하지 않는다.
